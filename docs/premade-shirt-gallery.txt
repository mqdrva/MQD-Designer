REVIEW
Open /template-preview.html for a phone-width or desktop-width demo, or
/design-gallery.html?demo=1 for the full-screen gallery. Five UNPUBLISHED review
fixtures using supplied original backgrounds exist only in v20/template-demo.js, never in the live catalog. Cards use
actual front/back panel renders from the existing editor's layer/silhouette code.
They are demonstrations, not approved editable launch designs.
Select a card, add Front/Back logos, edit the prefilled Back phone/services, review the shirt,
and use Save Design / Reopen saved demo for a browser-local round trip. Ordering,
account actions, sharing and processing actions are blocked in demo mode before
competing guest handlers can run. No real payment or order should be attempted.
The ordinary public gallery is empty until actual owner versions are published.

WHAT CHANGED
A narrow Start with a design link accompanies the existing homepage designer CTA.
Scratch-design entry remains. Gallery supports multiple categories per design and
shows populated category filters only, without search. Editor layer controls lock
source artwork and guide logo/text replacement. Replacement logos fit their original
slot with aspect ratio intact, including repeated replacements. Saved template
copies get independent layer/copy/design IDs and private uploaded logo paths.
The actual garment mapping source, geometry, templates and calibration are unchanged.

Owner Shirt Templates reuses existing owner session and MFA. It creates drafts
from the signed-in owner's own saved 3D designs, lets the owner choose layer roles,
name, categories and range label, attach actual Front/Back previews, preview the
draft, publish a new immutable version, or unpublish it. Garment is inherited exactly
from the source: this release does not auto-convert a look to another garment/range.
Public catalog data is separate from private customer_designs, whose grants/policies
are unchanged. Only the authenticated admin+MFA server handler edits/publishes.
Publishing copies deliberately approved master images into unique version paths in
a dedicated public bucket; draft previews remain private. Published versions/assets
remain available for existing customer copies and orders after unpublishing.
Both guest/account submission and final checkout validate the immutable version,
locked layers, garment/mapping, required sample replacements and logo-content hash.
Canonical locked master files are fetched server-side, ignoring substituted client
files. Existing checkout pricing, cart handoff, print/export and payment logic stay.
